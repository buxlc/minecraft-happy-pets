# HappyPets 1.0.2

捕获并养成原版生物作为宠物，支持召回、跟随、属性强化和骑乘。插件不需要数据库、客户端模组或其他前置插件，适用于 Spigot 1.21.4 / Java 21。

## 安装与上手

1. 把 `HappyPets-1.0.2.jar` 放进服务器的 `plugins` 文件夹，完整重启服务器。
2. 管理员执行 `/pets give 自己的名字 16` 获取宠物饲料；玩家也可以用 **小麦 + 苹果 + 糖 + 骨头** 无序合成 **2 份**。
3. 主手拿着饲料右键生物，即可捕获。再次喂自己的宠物可获得成长值、亲密度并回复生命。
4. **蹲下右键宠物**打开界面；也可以执行 `/pets` 管理全部宠物。
5. 默认最高 50 级、10 级成年；每次升级得到 2 个强化点，可提升速度、生命、跳跃。默认每人最多 5 只、同时放出 1 只。

末影龙、凋灵、监守者、远古守卫者始终无法捕获。玩家、盔甲架、NPC、其他玩家已驯服的动物，以及正在被骑乘或拴住的生物也无法捕获。其余可生成的原版 Mob 均可建立宠物记录，包括敌对生物、水生生物和嘎枝。

## 宠物界面

提供召唤/收回、跟随/原地等待、改名、喂食、小游戏、骑乘、三项属性强化及告别操作。改名后在聊天中输入 1—32 个字符的新名字，输入 `cancel` 取消，60 秒超时。名字不接受控制字符和颜色代码。

宠物成年前，支持幼年形态的生物显示幼年外观；其他生物使用缩小外观。成年后恢复对应形态和体型。羊毛颜色、猫/狼/青蛙/鱼/马等常见变种、史莱姆和幻翼体型、盔甲、手持物、狼铠、马类背包、猪和炽足兽的鞍等会随宠物存档保留。

**永久告别会删除宠物记录和实体，宠物携带的物品也会一并移除。** 此操作有第二次确认；请在捕获前取下需要留给玩家的装备与背包物品。宠物化之后的原生背包、交易、剪毛、挤奶、装桶和原版交互会被关闭，以免绕过宠物存档产生重复物品。此插件把生物转成趣味伙伴，不保留村民交易列表等全部原版生物内部状态。

## 互动与成长

| 方式 | 默认成长值 | 默认亲密度 | 限制 |
| --- | ---: | ---: | --- |
| 喂宠物饲料 | 40 | 5 | 每只宠物 30 秒一次 |
| 寻找零食 | 80 | 15 | 九格中找到指定食物 |
| 记忆足迹 | 92 | 17 | 记住并点击完整亮灯顺序 |
| 默契反应 | 按反应速度调整 | 按反应速度调整 | 等变绿再点击，抢跑失败 |
| 陪伴旅行 | 15 | 1 | 累积移动 40 格，至多每 20 秒发一次 |

三种小游戏共享每只宠物 60 秒冷却，**开局即开始计时**。失败、关闭或 45 秒超时都不发奖；成功只结算一次。先召唤宠物，并在它附近 16 格内开始游戏。移动每秒采样一次，旅行奖励按配置周期结算；明显跳跃传送不计距离，原地等待的宠物不参与。升级需求为 `ceil(xp-base × xp-factor ^ (当前等级 - 1))`，亲密度默认上限 1000。

默认每级强化点为 2，强化一次消耗 1 点：速度 +6%，最大生命 +2，跳跃初速度 +0.02。各项强化次数有独立上限。强化速度会同时影响跟随和骑乘，牛也可以成为高速坐骑；所有坐骑的移动速度受统一上限约束。

## 骑乘

成年后点击宠物界面的“骑乘”，或空手右键已放出的成年宠物。使用 **WASD** 移动、**空格**跳跃或上升、**Shift**下马。移动方向跟随玩家朝向，飞行或水中前进时可通过视角俯仰改变高度。飞行宠物下马会短暂获得缓降。

默认飞行种类：蝙蝠、鹦鹉、蜜蜂、悦灵、幻翼、恼鬼、恶魂、烈焰人。水中骑乘种类：鳕鱼、鲑鱼、热带鱼、河豚、海豚、鱿鱼、发光鱿鱼、美西螈、海龟、守卫者。其他种类按地面坐骑处理。管理员可以修改类型列表、基础速度、最高速度、飞行高度和开关。水生宠物需要附近有足够水域才能召唤和骑乘；关闭飞行骑乘时，飞行宠物仍可作为跟随伙伴。

使用 Spigot 原生乘客与输入 API，不修改玩家的飞行权限。移动遵循服务器碰撞，不能穿墙；跟随采用轻量移动和小台阶跳跃，远离主人后寻找已加载的安全位置传送，不运行复杂寻路。长距离传送、跨世界、主人死亡、离线、区块/世界卸载和服务器关闭时会收回宠物，再从列表召唤即可。

## 命令与权限

命令别名：`/pet`、`/happypets`、`/hpets`。编号按照 `/pets` 列表顺序，从 1 开始。

| 命令 | 用途 | 权限 |
| --- | --- | --- |
| `/pets`、`/pets list` | 打开宠物列表 | `happypets.use` |
| `/pets help` | 查看帮助 | `happypets.use` |
| `/pets summon [编号]` | 召唤指定宠物 | `happypets.use` |
| `/pets recall` | 收回当前宠物 | `happypets.use` |
| `/pets ride [编号]` | 骑乘成年宠物 | `happypets.use` |
| `/pets rename [编号] [新名字]` | 改名，也支持聊天输入 | `happypets.use` |
| `/pets admin` | 管理员设置界面 | `happypets.admin` |
| `/pets adminpets` | 浏览全服宠物，包含离线主人 | `happypets.admin` |
| `/pets inspect <宠物UUID>` | 打开指定宠物菜单 | `happypets.admin` |
| `/pets edit <宠物UUID> <字段> <数值>` | 直接修改指定宠物数据 | `happypets.admin` |
| `/pets give [在线玩家] [数量]` | 发放饲料，默认自己/16份 | `happypets.admin` |
| `/pets reload` | 验证并重载配置和语言 | `happypets.admin` |
| `/pets save` | 立即提交一次异步保存 | `happypets.admin` |

`happypets.use` 默认所有玩家拥有，`happypets.admin` 默认仅 OP。给他人发放饲料时必须是在线玩家，数量范围 1—2304；背包放不下的饲料会掉在接收者脚下。关闭功能后仍可通过 `/pets recall` 收回宠物。界面不显示玩家无权操作的管理入口，点击时重新校验权限和归属。

## 管理员配置

拥有 `happypets.admin` 的管理员可以**蹲下右键任何宠物**打开菜单，也可从管理员设置页的“全服宠物”入口进入。全服列表按主人分组，包含离线玩家的宠物，显示主人和宠物 UUID。打开宠物菜单后选择“编辑宠物数据”。管理无需 `happypets.use`，系统关闭或身处玩法禁用世界也能处理记录。

编辑面板可以修改等级、总成长值、亲密度、强化点、速度/生命/跳跃强化等级、基础最大生命和基础移动速度。左键增加、右键减少，Shift 加大步幅；点击对应的姓名牌或中键可在聊天中直接输入数值，`cancel` 取消，60 秒超时。修改立即刷新已放出的宠物，多次同 tick 修改合并后提交本地异步保存。

直接调等级会把总成长值设置为对应等级起点，不自动发放或扣除强化点；调成长值也不会触发升级奖励。亲密度和强化点支持 0—2147483647，强化级别支持 0—1000，管理员可超过普通培养上限；实际坐骑速度仍有统一上限。等级范围为 1—配置的最高等级，总成长值为 0—9223372036854775807；基础最大生命大于 0 且不超过 1024，基础移动速度为 0—1024。界面显示各项有效范围，拒绝负数、溢出及非有限数值。

管理员能改名、收回、调整跟随方式和删除其他主人的宠物，宠物归属保持不变。收回只作用于选中的宠物；跨主人管理菜单不提供召唤、骑乘、喂食和小游戏。每次点击和聊天提交都会重新验证权限，撤销管理权限后不能继续编辑他人的宠物。后台记录直接编辑的操作者、宠物编号、字段和数值。

命令示例：`/pets edit <宠物UUID> level 20`、`/pets edit <宠物UUID> bond 8888`。字段名分别为 `level`、`xp`、`bond`、`points`、`speed`、`health`、`jump`、`base-health`、`base-speed`。这些单宠物管理命令需在游戏内执行。

`/pets admin` 提供分页设置界面：系统/小游戏/骑乘/飞行/免伤/合成开关，宠物数量、成年/最高等级、成长曲线、各奖励与冷却、强化上限与增量、移动速度、飞行高度、跟随距离和更新间隔、自动保存周期。左键增加、右键减少，Shift 加大步幅；开关可直接切换，修改后保存并即时应用。还可以领取饲料、重载配置和语言。

以下列表和物品选项直接编辑 `plugins/HappyPets/config.yml` 后执行 `/pets reload`：

```yaml
language: zh_CN
capture:
  excluded-types: []
  disabled-worlds: []
feed:
  material: COOKIE
  recipe-enabled: true
riding:
  flying-types: [BAT, PARROT, BEE, ALLAY, PHANTOM, VEX, GHAST, BLAZE]
  aquatic-types: [COD, SALMON, TROPICAL_FISH, PUFFERFISH, DOLPHIN, SQUID, GLOW_SQUID, AXOLOTL, TURTLE, GUARDIAN]
```

这只是选项示例，保留完整文件的其他节点。生物类型使用 Spigot 1.21.4 的枚举名称。`feed.material` 仅影响新生成饲料的外观，旧饲料依然通过内部标识识别，普通物品改名不能冒充。配置包含类型和数值范围校验；成年等级不得超过最高等级，传送距离必须大于跟随距离。非法修改会拒绝应用并记录后台日志。

## 独立语言文件

首次启动生成 `plugins/HappyPets/lang/zh_CN.yml` 与 `en_US.yml`。在 `config.yml` 中选择 `language: zh_CN` 或 `en_US`，也可以复制为自定义文件并填入不带 `.yml` 的文件名。聊天提示、菜单标题、按钮、说明、常见生物与小游戏食物名称均从语言文件读取，支持 `&` 颜色代码和 `{name}` 等占位符。

修改后执行 `/pets reload`。缺失的键使用内置中文回退；无效 YAML、错误值类型、缺失语言文件和不合法文件名会拒绝重载。重载会关闭已有菜单和游戏，防止旧界面继续操作。

## 本地数据与性能

运行数据全部位于服务器的 `plugins/HappyPets/`：`config.yml`、`lang/`、`pets.yml`、`pets.yml.bak`。无需 MySQL/SQLite，不写玩家本机目录。备份请在正常停服后复制整个插件文件夹。若数据损坏，插件会拒绝启动并保留原文件；停服后检查错误，或用备份恢复 `pets.yml`。

- 内存按宠物 ID、主人和已放出实体索引。只有已放出的宠物参与跟随，每个在线主人至多一只；离线宠物不生成实体、不执行更新。
- 共用一个每 tick 调度器；骑乘仅更新当前骑手，跟随默认每 10 tick，移动采样每秒。没有每 tick 全世界实体扫描，也不为宠物保持区块加载。启动时仅清理一次已加载区块中的旧宠物实体，之后使用区块事件处理。
- 默认每 60 秒自动保存。主线程复制数据和必要的物品状态，YAML 宠物记录编码及文件写入由独立单写入线程完成；连续快照合并，先写临时文件再原子替换，保留上一份备份。正常停服等待最终写入。
- 喂食、游戏、旅行奖励均有限频；速度、飞行高度、宠物数量和强化次数均有上限。默认关闭宠物自主行为、攻击、爆炸、方块破坏、自然繁殖及变身，宠物死亡不掉物品和经验，而是保留记录收回。

原子替换用于避免半写文件，不能代替整机备份。进程被强制结束或机器断电时，尚未落盘的成长进度可能回退，默认最多约一个自动保存周期。保存失败会在后台报错。服务器实际承载量仍取决于在线人数、种类、视距和其他插件；本版本没有实服压力测试数据。

## 其他插件与 API

已取消的右键交互不会触发捕获。另提供同步、可取消的 `cn.bucheng.happypets.PetCaptureEvent`，领地/自定义生物插件可以检查 `getPlayer()` 与 `getEntity()` 并取消捕获。尚未专门适配 WorldGuard、Citizens、MythicMobs 或各类反作弊插件，请在测试服验证已有组合；复杂自定义生物建议加入 `capture.excluded-types` 或监听捕获事件。不会宣称保留第三方生物的全部自定义状态。

## 构建与验证

```powershell
.\build.ps1
```

脚本从 `JAVA_HOME` 和 `PATH` 查找已有的 Java 21、Maven，不会安装工具。依赖缓存和临时文件默认放在 F 盘；可用 `-JdkHome`、`-MavenHome`、`-Repository`、`-TempRoot` 指定位置。输出为 `target/HappyPets-1.0.2.jar`。

自动化检查覆盖成长计算/溢出/强化消耗、配置关联范围、语言回退与重载、异步存档与最终快照、数据损坏拒写、权限与归属、喂食消耗与冷却、游戏单次结算、移动速度上限、原生背包防护和 GUI 转移物品拦截。尚未连接真实 Minecraft 客户端验证骑乘手感、特殊生物运动和第三方插件兼容；上线前请在测试服验证这些交互。
